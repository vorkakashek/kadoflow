These images are material and object references, not a collage to reproduce literally.

## Recommended grouping in Krea

1. **Composition inputs:** the selected original ikebana reference plus the Kadoflow layout sketch.
2. **Natural forms:** `01`, `02`, `07`, `08`.
3. **Synthetic materials:** `03`, `04`, `05`, `09`, `10`.
4. **Black stone:** `06`.

Do not send every image at maximum influence. Composition references should control geometry; material references should have lower influence and be described explicitly in the prompt.

Run low-resolution generations first. Send only the selected result to edit/inpaint, then to Magnific Precise at 2x. Do not put the upscaler inside the automatic generation loop.
