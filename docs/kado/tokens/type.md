# Type

Кегли. На контрольных точках — шаг **4** (половина 8dp).

## Значения (px)

| Токен | 390 | 768 | 1280 | 1440 | 1920 | 2560 | CSS |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| `type.body` | 16 | 16 | 20 | 20 | 20 | 20 | `--type-body` |
| `type.lead` | 20 | 20 | 24 | 24 | 28 | 28 | `--type-lead` |
| `type.nav` | 16 | 16 | 20 | 20 | 20 | 20 | `--type-nav` |
| `type.slogan` | 20 | 20 | 28 | 32 | 40 | 40 | `--type-slogan` |
| `type.display` | 40 | 48 | 64 | 72 | 80 | 80 | `--type-display` |
| `type.hero` | 32 | 40 | 64 | 72 | 80 | 88 | `--type-hero` |

## Роли

| Токен | Где |
| --- | --- |
| body | основной текст |
| lead | лиды, усиленные абзацы |
| nav | служебная навигация / мелкие подписи |
| slogan | слоган вверху hero + описание под h1 |
| display | крупные заголовки вне hero |
| hero | главный заголовок первого экрана (на мобилке скромнее, с 1280 крупнее display) |

Шапка сайта сейчас чуть крупнее чистого `nav`: смесь nav+lead в компоненте — исключение, не новый токен.

## Важно про rem

```css
html { font-size: 100%; }   /* стабильный rem */
body { font-size: var(--type-body); }
```

Не вешать `--type-body` на `html` — иначе `h-8`, `p-2` и прочий rem поедут вместе с fluid.

## Начертание

Семейство: **Outfit** (через `@nuxt/fonts`). Веса в продукте: 400 / 500 / 700. Трекинг крупных кеглей обычно слегка отрицательный (`-0.02em`).
