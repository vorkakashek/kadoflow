# Motion

Пока motion-токены живут в CSS (`app/assets/css/main.css`), не в `responsive.json`. Ориентир по ощущению — короткие UI-переходы в духе студийных сайтов (~200–300ms, `ease`).

## Переменные

| Токен | Значение | Зачем |
| --- | --- | --- |
| `--motion-fast` | `0.2s` | мелкий transform / фон |
| `--motion-base` | `0.3s` | opacity, чипы, типовой hover |
| `--motion-layout` | `0.5s` | схлопывание шапки, крупные layout-морфы |
| `--motion-ease` | `ease` | без «премиум» cubic по умолчанию |
| `--motion-hover-opacity` | `0.7` | hover ссылок |

## Поведение шапки

- Схлопывание в `content-max` — после **~220ms** задержки на скролле (не мгновенно).
- Возврат наверх — сразу.
- Анимация ширины / высоты — `--motion-layout`.

## Scroll / surface

Отдельные сценарии (soft snap секций, GSAP scrub, дыхание края surface) **не** сводятся к этим четырём переменным — описываются в коде компонента и при необходимости выносятся сюда позже отдельными подразделами.
