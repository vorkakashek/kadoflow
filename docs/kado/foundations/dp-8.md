# Шкала 8dp

Kado стоит на **density-independent** сетке с базовым шагом **8**.

## Зачем

Одинаковый ритм в Figma и в коде. Меньше «случайных» 13px / 37px. Легко складывать отступы: 8 + 16 + 24 = 48.

## Правила

| Слой | Шаг на контрольных точках | Примеры |
| --- | ---: | --- |
| Layout / space | **8** | 16, 24, 32, 40, 48, 56, 80, 112, 160… |
| Type | **4** (половина 8) | 16, 20, 24, 28, 32, 40, 48, 64, 72, 80 |
| Radius | **4** | 4 (и дальше 8, 12… если понадобится) |

**На контрольных ширинах** в `responsive.json` пишем только значения с этих шагов.  
**Между** ширинами `clamp()` может дать `37.4px` — так и задумано, не округлять вручную.

## Запрещено на контрольных точках

- layout/space: `36`, `44`, `17`, `19`, `220` (если не кратно 8);
- type: `17`, `19`, `22`, `34` — сдвинуть к ближайшему шагу 4.

## Tailwind и rem

- `html { font-size: 100% }` — rem стабилен (16px).
- Tailwind `p-4` / `gap-2` — только **внутренняя** мелочь компонентов.
- Рамка экрана, секции, типографика страницы — **только токены** `--layout-*` / `--space-*` / `--type-*`.

Иначе fluid body-кегль раздует rem-утилиты и сломает слот шапки.

## Связь с fluid

8dp задаёт **якоря**. Fluid задаёт **переход** между якорями. См. [Fluid-интерполяция](./fluid.md).
