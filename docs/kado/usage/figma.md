# Figma

## Цвета

1. Variables → новая коллекция (например `Kadoflow Colors`).
2. Перетащить `kadoflow-colors-light.json` и `kadoflow-colors-inverse.json`.
3. Modes → `Light` / `Inverse`.
4. В макетах брать **`semantic/*`**, не сырой `palette/*`, кроме осознанных исключений.

## Размеры

Figma Variables для fluid пока не генерируются автоматически из `responsive.json`. Рабочий процесс:

1. Проектировать на контрольных ширинах **390 / 768 / 1280 / 1440** (минимум).
2. Ставить отступы и кегли **из таблиц** docs / JSON (8dp / 4 type).
3. Wide 1920 / 2560 — проверять рост, не рисовать отдельный «четвёртый мир», если композиция та же.

## Сетка

12 колонок, margin = gutter на каноне 1440 → **40 / 40**.
