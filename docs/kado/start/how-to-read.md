# Как читать эту документацию

Документация устроена как у API / SDK: слева разделы, справа одна тема.

## Структура файлов

```text
docs/kado/
  _nav.json          ← дерево сайдбара (для будущей платформы)
  index.md           ← обзор
  foundations/       ← принципы
  tokens/            ← справочник значений
  layout/            ← сетка и рамка
  usage/             ← как применять
```

Каждый `.md` = один пункт меню. `slug` в `_nav.json` = путь без расширения.

## Откуда брать правду

| Вопрос | Где ответ |
| --- | --- |
| Какие px на 1440? | Страница токена + `design-tokens/responsive.json` |
| Как получается `clamp()`? | [Fluid](../foundations/fluid.md) + `scripts/generate-fluid.mjs` |
| Какой CSS-класс / переменная? | [CSS-переменные](../usage/css-variables.md) |
| Цвета в Figma | [Color](../tokens/color.md), [Figma](../usage/figma.md) |

Если таблица в docs и JSON разошлись — **побеждает JSON**, docs правят следом.

## Соглашения в тексте

- **Контрольная ширина** — одна из 390 / 768 / 1280 / 1440 / 1920 / 2560.
- **Токен** — имя вроде `layout.margin` → CSS `--layout-margin`.
- **dp-8** — шаг 8px на контрольных точках для space/layout; type — шаг 4.

## Перенос на платформу

1. Импортировать папку `docs/kado/` как раздел «Kado».
2. Построить сайдбар из `_nav.json`.
3. Рендерить Markdown (таблицы, код, внутренние ссылки).
4. Опционально: подтягивать таблицы токенов из JSON автоматически (позже).
