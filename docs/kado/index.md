# Kado

**Kado** — дизайн-система студии Kadoflow: кусочный fluid, база **8dp**, токены размеров/типа/цвета и 12-колоночная сетка.

Эта папка (`docs/kado/`) — **каноническая документация для людей**. Источник правды для чисел в коде: `design-tokens/responsive.json` (+ цвета в DTCG JSON). После финализации содержимое переносится на docs-платформу с админкой: структура уже заточена под сайдбар слева.

## Для кого

- ты и команда, когда собираете сайт студии или клиентский проект «на Kado»;
- дизайнеры — брейкпоинты, dp-8, Figma Variables;
- разработчики — CSS-переменные, генерация `clamp()`, сетка.

## Быстрый старт

1. Прочитай [Шкалу 8dp](./foundations/dp-8.md), [Брейкпоинты](./foundations/breakpoints.md) и [Мобильный viewport](./foundations/viewport.md).
2. Открой таблицы [Layout](./tokens/layout.md) / [Space](./tokens/space.md) / [Type](./tokens/type.md).
3. В коде бери только `--layout-*`, `--space-*`, `--type-*` — не хардкодь отступы «на глаз».

## Навигация

Полное дерево разделов — в [`_nav.json`](./_nav.json). На платформе этот файл = конфиг левого меню.

| Группа | Что внутри |
| --- | --- |
| **Основы** | 8dp, брейкпоинты, fluid, мобильный viewport |
| **Токены** | значения на каждой контрольной ширине |
| **Раскладка** | 12 колонок, рамка экрана, шапка↔hero |
| **Практика** | CSS, Figma, типичные ошибки |

## Статус

Черновик v0.1 под живой сайт kadoflow. Таблицы синхронизированы с `responsive.json` на момент написания. При смене токенов — обновить соответствующую страницу в `tokens/`.
